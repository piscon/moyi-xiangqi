# 墨弈 · 水墨棋局

把棋盘搬进水墨画里——一款水墨风中国象棋。单文件、纯前端、无后端，打开就能下。

## ▶ 在线试玩

**https://piscon.github.io/moyi-xiangqi/**

手机、电脑浏览器都能玩，进度自动保存在本机。也可以在小红书 App 里搜「墨弈 · 水墨棋局」，玩已发布的小工具版。

## 玩法

- **双人对局**：一部手机，两个人面对面，一人执红一人执黑。点选或拖动棋子落子，悔棋商量着来。
- **人机对弈**：三档 AI（陪练 / 对手 / 高手），陪你慢慢变强。
- **闯八关**：连闯八位武侠风高手，棋力从 855 一路到 1712。排位只认本地最高纪录，只升不降；赢了直接进下一关。
- **残局**：33 道古谱残局，全部出自《适情雅趣》，并经页面引擎的精确解算器逐题验证（必杀成立、钥匙步唯一）。解开一题得一枚朱砂印，用过提示的是淡印；里程碑成就：首解 / 半壁（解满一半）/ 全解。

## 规则

采用民间对弈规则，宽松好上手：

- 「自杀步」允许走，将军只是闪烁提示、不禁手，胜负以吃掉对方将（帅）为准。
- 死循环有裁定：第 3 次重复局面时判定——单方长将、长捉、一将一捉判负；帅（将）和兵（卒）长捉为例外，与双方互将等情形一律判和。AI 不会走进判负循环。
- 可选计时（默认关）：局时 10 / 15 / 20 分钟，局时耗尽进入 30 秒读秒，超时判负。
- 认输、重开都要点两次确认；终局后一键「再来一局」。

## 体验细节

- 拖拽走子与点选并存，落子有分级震动和 WebAudio 合成音效（落子木声、吃子闷响、将军脆响）。
- 终局落印：胜盖朱砂实印，负盖淡墨印，和棋半淡。
- 四种界面语言：简体中文 / 繁體中文 / English / 日本語（棋面字与棋谱记法不翻译，记法跟随界面语言的字形）。
- 单屏不滚动布局，手机与桌面自适应，含全屏沉浸模式。

## 技术

整个游戏就是一个 `index.html`：原生 JS 引擎（negamax + α-β 剪枝 + 静默搜索 + 置换表）在访问者设备上运行，无服务器、无账号，存档只进浏览器 localStorage。
